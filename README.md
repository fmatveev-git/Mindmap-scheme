# Mindmap-scheme

Планировщик работ в виде mind-map: проекты, дерево задач любой вложенности, гипотезы, оценки, исполнители, статусы, стрелки между блоками, свободные фигуры, палитры, импорт (JSON / OPML / markdown / списки) и экспорт в JSON.

Одно-файловое приложение (`index.html`, без сборки и зависимостей). Данные хранятся в `localStorage` браузера — перед переездом на другой адрес или браузер делайте экспорт JSON.

## Запуск
Откройте `index.html` в браузере или включите GitHub Pages (Settings → Pages → Source: GitHub Actions). Адрес: `https://fmatveev-git.github.io/mindmap-scheme/`.

## Схемы в репозитории
Файл `data.json` в корне хранит все проекты и деплоится вместе с сайтом.
- Новый браузер (без своих схем) сразу открывает схемы из `data.json`.
- Если в браузере уже есть схемы, а `data.json` обновился, сайт спросит, загрузить ли новую версию. Прежние схемы остаются в резервной копии: «Импорт / экспорт → Вернуть прежние».
- Чтобы обновить схемы в репозитории: «Импорт / экспорт → Скачать data.json» (или «JSON всех проектов»), затем загрузите файл в корень репозитория (Add file → Upload files) с заменой.

Правки в браузере сами в репозиторий не уходят: они хранятся в `localStorage`, пока вы не выгрузите `data.json`.

## Горячие клавиши
Tab — дочерний блок, Enter — соседний, Delete — удалить, Ctrl/Cmd + C / X / V — копировать / вырезать / вставить, двойной клик — переименовать.
